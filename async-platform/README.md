# async-platform переехал в Асинхронус

Стенд, с которого начинался Асинхронус — ECS-прототип, JMH-бенчи, JFR-профилировщики
и доки-исследования по тику Minecraft — с 15.08.2026 живёт в репозитории проекта:

**`D:/Asynchronus` → `research/async-platform`** ([GWSAnyone/asynchronus](https://github.com/GWSAnyone/asynchronus))

История переехала вместе с кодом: `git log -- research/async-platform` в том
репозитории отдаёт исходные 39 коммитов от 16–25 июля с их датами и мотивировками.

## Почему переехал

Этот репозиторий — форк фреймворка агентов TAUSIK (`Okianiwa/tausik-core`), а стенд
жил внутри него по историческим причинам: ядро действительно начинали здесь. Когда
боевая реализация выросла в отдельный репозиторий, код по Minecraft оказался разделён
между двумя, и это давало ложные вердикты гейтов — verify рапортовал «deliverables
missing», потому что искал результат работы не в том репозитории.

## Что уехало вместе с кодом

- **93 записи проектной памяти** про Minecraft, ECS, cluster/census, Folia, замеры —
  в базу TAUSIK Асинхронуса. 44 записи про сам фреймворк остались здесь.
- **54 задачи и летопись сессий** — в `docs/history/` Асинхронуса архивом: их статусы
  и даты закрытия воспроизвести записями в чужой базе нельзя, а терять — жалко.
- **Тесты `test_perf_parse.py` и `test_tick_probe.py`** — уехали к своим модулям.
  `test_tick_probe` нацелен на живую версию в `tools/bench`, а не на снимок стенда.

## Что осталось в этом каталоге

Только игнорируемые git локальные артефакты: JRE, скачанный сервер Minecraft,
build-кэши Gradle. Они никогда не были под версионным контролем (и не должны быть —
гейт `mojang_artifact_scan` отказывает в коммите артефактов Mojang, в том числе по
новому пути). Каталог можно удалить целиком, когда он перестанет быть нужен локально.
