# async-platform/mc — всё по Minecraft

Одна папка на весь майн: скрипт установки, разведка, замеры. Ничего от Mojang в git не едет.

## Граница лицензии — читать первым

**Деобфусцировано ≠ открыто.** Mojang сохраняет собственность на исходники; с выходом 26.x
лицензия не менялась. Разрешение на использование **для себя** получено через техподдержку;
выкладывать не планируем.

**Код и артефакты Mojang не коммитятся никогда.** В git едут только: этот README, скрипт
установки, наши выводы. `.gitignore` рядом написан запретительно (игнорит `*`, разрешает
поимённо) — перечисление расширений протекает на первом же артефакте, о котором не подумали.

Оговорка, добытая опытом (dead end #34): `.gitignore` защищает от **случайности**
(`git add .`, `commit -a`) — это 99% реального риска. От `git add -f` он не защищает
**в принципе**: флаг для того и существует. Механическая защита от намеренного `-f` — гейт на
коммите; заведён отдельной задачей.

## Установка

```bash
python setup_mc_server.py --provision-java --accept-eula
```

- `--provision-java` — качает Temurin JDK 25 в `jre/`, если системная не годится.
  **26.2 требует Java 25** (1.21.11 требовал 21); на этой машине были 17/21/24 — ни одна не
  подходит.
- `--accept-eula` — записывает `eula.txt=true`. Это **принятие лицензии Mojang**, поэтому флаг
  явный: скрипт не принимает чужое соглашение молча.
- Идемпотентно: jar с сошедшимся sha1 не перекачивается, мир не затирается.

Проверить без скачивания: `--check-only`.

## Что скрипт гарантирует

- Источник **только официальный**: `version_manifest_v2` → version json → `downloads.server`.
  URL не хардкодится (он объектный и меняется от версии к версии), а выводится из манифеста.
- sha1 проверяется **дважды**: у version json (из манифеста) и у самого jar. Несовпадение —
  **отказ и удаление**, а не предупреждение.
- Читаемость проверяется у **вложенного** сервера, а не у бандлера (см. ниже).

## Запуск

```bash
cd server
../jre/jdk-25.0.3+9/bin/java.exe -Xmx4G -jar minecraft_server.26.2.jar nogui
```

Проверено: `Starting minecraft server version 26.2` → `Done (1.703s)! For help, type "help"`.

## Грабли, на которые уже наступили

**Бандлер врёт о читаемости.** Внешний `minecraft_server.26.2.jar` — это загрузчик: в нём
4 класса `net/minecraft/bundler/Main*`, и они читаемы **всегда**, даже у обфусцированных версий.
Настоящий сервер лежит внутри: `META-INF/versions/26.2/server-26.2.jar` (25 МБ, 7 445 классов).
Проверка по внешнему jar-у даёт ложное «деобфусцировано».

**Ванильный сервер паузит тик без игроков** — `Server empty for 60 seconds, pausing`.
Профилировщик на пустом сервере измерит **паузу** и выдаст правдоподобные нули по блок-энтити.
Критично для `mc-tick-profile`; подробности и варианты обхода — memory #35.

**`/tps` в ванили нет** — это команда Paper/Spigot.

**Adoptium отдаёт 403** на дефолтный User-Agent urllib — заголовок обязателен.

## Чем доказана деобфускация

Не анонсом, а двумя независимыми фактами:

1. В `downloads` версии 26.2 **нет** `client_mappings` / `server_mappings`. У 1.21.11 они есть.
   Mojang перестал публиковать ProGuard-маппинги — отображать больше нечего.
2. Внутри артефакта: 7 445 классов, из них 7 434 в `net/minecraft/*`, классов с именами
   ≤2 символов — **ноль**.
